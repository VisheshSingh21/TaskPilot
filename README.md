## 📌 About The Project

**TaskPilot** is an AI-powered task management application designed to simplify the process of converting meeting discussions into actionable tasks.

In a typical meeting, important decisions and responsibilities can easily get lost in lengthy conversations. TaskPilot aims to solve this problem by using AI to help identify actionable information and organize it into structured tasks.

## 🚀 Run Locally

```bash
git clone https://github.com/VisheshSingh21/TaskPilot.git

cd TaskPilot

npm install

npm start
```

Configure your required environment variables in `.env` before starting the application.
